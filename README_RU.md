# Бенц Медикал ВРН — сайт и редактор

## Быстрый старт

1. Откройте `benz-studio.html` в современном браузере. Установка и интернет не нужны.
2. Нажмите **Редактор сайта** справа внизу.
3. Нажмите на текст на странице и отредактируйте его. В списке **Изменить контейнер** можно выбрать кнопку, карточку или секцию и задать цвет фона, текста, границы. Во вкладке **Тексты** — поиск по всем текстовым полям.
4. Во вкладке **Цвета** задайте общий акцент и палитру. У каждого элемента возможен собственный цвет; кнопка сброса возвращает наследование темы.
5. Фото врачей и картинки можно заменить: выберите область изображения, затем загрузите PNG/JPEG/WebP/SVG до 6 МБ. Изображения встраиваются в итоговый HTML.
6. **Скачать готовый сайт · ZIP** выгрузит `index.html` без редактора, `benz-studio.html` с редактором, JSON-проект и краткую инструкцию. Варианты HTML доступны отдельными кнопками.

Все файлы автономные, шрифты системные (Arial / Helvetica). Фирменные шрифты HelveticaNeueCyr и CeraPro не приложены к исходным материалам отдельными лицензированными файлами и не извлекались из PDF. Логотип Бенц и 16 этикеток BIORISE взяты из предоставленных PDF. Объёмные изображения капельницы и портреты-заглушки созданы средствами CSS/SVG. Реальных фотографий врачей в материалах не было.

## Содержимое архива

- `index.html` — версия для посетителей. Можно открыть двойным кликом или разместить на обычном статическом хостинге, GitHub Pages, nginx.
- `benz-studio.html` — готовая редактируемая версия.
- `benz-project.json` — исходная конфигурация: тексты, цвета, изображения, услуги, группы, демонстрационное расписание.
- `source/` — исходники без внешних зависимостей.

Код редактора отсутствует в публичном HTML. Не выкладывайте `benz-studio.html` и JSON-проект на публичный хостинг, если хотите опубликовать только версию для посетителей. Редактор меняет локальную копию и экспорт, а не серверный сайт. После правок замените размещённый `index.html` экспортированным файлом.

## Сохранение и перенос

Автосохранение хранит только настройки сайта в localStorage браузера. Данные демонстрационной формы записи не сохраняются и не отправляются. Если localStorage недоступен или переполнен, редактор сообщит об этом: скачайте JSON-проект или HTML с редактором.

JSON-проект можно загрузить во вкладке **Настройки**. Перенос на другой компьютер: скачайте HTML с редактором или загрузите JSON в исходный редактор. Кнопки **Отменить** и **Повторить** работают в текущем сеансе. **Сбросить все изменения** возвращает состояние файла, который был открыт (для экспортированного HTML — состояние на момент экспорта).

При добавлении новых элементов через JSON каждому нужен уникальный `id`. Для врачей используются `id`, `name`, `specialty`, `experience`; для анализов — `id`, `name`, `group`, `price`, `term`; для капельниц — `id`, `name`, `asset`, `color`, `group`. Значения групп `a`, `b`, `c` соответствуют трём вкладкам. Названия вкладок редактируются. Текстовые правки по ID в `texts` имеют приоритет над полями записей.

## Контакты, карта и документы

Во вкладке **Настройки** задайте телефон, email, адрес. Телефон становится ссылкой `tel:`. Затем добавьте полный URL карты из атрибута `src` iframe Яндекс.Карт или Google Maps. Нужна именно ссылка виджета, а не ссылка на обычную страницу карты. В исходном состоянии показана явно помеченная схема без выдуманной точки клиники.

В настройках доступны ссылки на политику конфиденциальности, лицензию и соцсеть. Без ссылок юридические окна показывают lorem ipsum с отметкой о том, что документ не предоставлен.

## Запись и МИС

**Текущее состояние — демонстрация.** Расписание тестовое: понедельник–суббота, несколько условных слотов на следующие 60 дней. Проверяются дата, имя, телефон, согласие. Кнопка не выполняет запросы и не создаёт запись: после проверки появляется явное сообщение, что данные не отправлены. Предвыбор врача, анализа и капельницы из карточки работает в локальной форме.

Для реальной записи во вкладке **Настройки** выберите:

- **Открывать расписание МИС** — вместо демоформы появится кнопка на предоставленный клиникой URL.
- **Встроить виджет МИС (iframe)** — расписание встраивается в секцию записи. МИС должна разрешать встраивание через CSP / X-Frame-Options. Под виджетом остаётся ссылка на отдельную вкладку.

Для этих режимов необходим URL расписания, которого нет в ТЗ. Конкретный предвыбор специалиста внутри внешней МИС, живые свободные интервалы, динамический прайс и отправка заявок через собственную форму требуют документации API / виджета и серверного адаптера. Они не имитируются как действующая интеграция. Прайс и левое расписание сейчас редактируемые локальные данные; они не синхронизируются с МИС.

Точки для подключения разработчиком: `B.renderAnalyses()` — прайс, `B.renderBooking()` — виджет/форма, `B.book(type,item)` — предвыбор из карточки. Не помещайте секретные API-ключи в HTML или JSON. При собственной интеграции сервер проверяет и резервирует слот; браузер не может гарантировать его доступность.

## Исходники и сборка

В папке `source/`:

- `src/style.css` — оформление, адаптивные и контейнерные запросы, состояния анимации, reduced motion.
- `src/app.js` — публичная часть, карточки, фильтры, форма и режимы МИС.
- `src/editor.js` — визуальный редактор, импорт JSON, отмена/повтор и экспорт ZIP без библиотек.
- `config.json` — исходные данные. Сборщик читает этот файл и сохраняет ваши изменения.
- `dist/assets/` — оригинальные изображения, необходимые для повторной сборки.
- `build.py` — сборка автономных HTML; только стандартная библиотека Python 3.

Запуск: `python3 build.py`. Результат `dist/index.html` — студия, `dist/site.html` — публичный сайт. Сборщик встраивает CSS, JS, изображения; Node.js и npm не нужны. Для проверки синтаксиса при наличии Node.js: `node --check src/app.js`, `node --check src/editor.js`.

Перед реальным запуском замените lorem ipsum, изображения врачей, контакты, документы, цены и подключите запись МИС.
